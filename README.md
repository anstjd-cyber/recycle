# 분리수거 챌린지

60초 동안 쓰레기를 알맞은 통에 분리배출하는 부스 체험 게임입니다.
안동 ICT 연구회 바이브코딩 체험 부스에서 쓰려고 만들었습니다.

- 시작 페이지: `index.html`
- 게임: `game/index.html`

## 하는 법

쓰레기가 나오면 알맞은 통의 번호 키(1~6)를 누르거나 통을 클릭합니다.
문제당 6초, 전체 60초입니다. 틀리면 정답과 그 이유를 보여줍니다.

| 키 | 통 |
|---|---|
| 1 | 일반쓰레기 |
| 2 | 종이 |
| 3 | 플라스틱 |
| 4 | 캔·고철 |
| 5 | 유리 |
| 6 | 비닐 |

운영자용 단축키: `O` 운영자 패널 · `D` 집계화면 · `Esc` 처음으로

## 부스에서 띄우기

`start.bat` 을 실행하면 로컬 서버가 뜨고 브라우저가 게임 화면으로 열립니다.
행사장 인터넷이 끊겨도 동작합니다(외부에서 받아오는 것은 시작 페이지의 글꼴뿐입니다).

## 점수

정답 100점, 연속으로 맞히면 1개당 20점씩 더해집니다(5단계 상한).
**오답은 감점하지 않습니다** — 점수를 깎으면 모르는 문제를 찍지 않고 넘기려 해서
배우는 순간이 사라집니다. 대신 정답과 이유를 보여주는 데 시간을 씁니다.

## 분리배출 기준

한국 가정용 6종을 따랐습니다. 지자체마다 세부 기준이 다를 수 있으니
실제 배출은 거주지 안내를 따라 주세요.
